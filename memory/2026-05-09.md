## 07:30 CEST — ACP Delivery Fix #2995

P1 — sessions reporting `delivered: true` but no Claude process spawned.

**Root cause:** `sendInitialPrompt()` stub always returns `{delivered: true, attempts: 1}`. In ACP mode, prompts go through the backend during session creation — this stub is only reached when `acpEnabled: false`. Nobody processes the prompt, but the API says it was delivered.

**Fix:** Changed stub to return `{delivered: false, attempts: 0}` — honest status.

**Real fix for users:** Enable ACP in config (`acpEnabled: true` or `AEGIS_ACP_ENABLED=true`). Without ACP, sessions are created but no Claude process runs.

**PR:** #3022 → develop
