## P0 — Prompt delivery reliability (branch: fix/prompt-delivery-reliability)
- **Root cause**: `sendInitialPrompt` had a single 15s timeout — too aggressive for CC cold starts
- **Fix**: 60s default timeout with 2 retries using exponential backoff (1.5x per attempt, capped at 2min)
- Total worst case: 60+90+120=270s (4.5min) — enough for even slow cold starts
- Added `prompt_delivery` metrics: sent/delivered/failed/success_rate in `/v1/metrics`
- Server tracks prompt delivery on both `/v1/sessions` and `/sessions` routes
