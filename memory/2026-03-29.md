### Aegis Competitive Position

**What Aegis does better:**
- Production HTTP API (REST) — not just CLI scripts
- Real session management (create/read/send/approve/kill)
- MCP server (full implementation with tools/resources/prompts)
- Auth system (Bearer + WebSocket handshake)
- Dashboard (React, live terminal, SSE)
- CI/CD integration (GitHub Actions, release automation)
- Type safety (Zod 4 validation everywhere)

**What competitors do better:**
- Shogun: multi-CLI support (4 CLIs vs our 1), YAML-based zero-overhead coordination, skill discovery
- Orchestrator Kit: 39 specialized agents (vs our workflow skill), context preservation, slash commands
- Codex Orchestrator: CC marketplace integration, mid-task follow-up

**Feature gaps to address (priority order):**
1. Multi-CLI support (Codex, Gemini, Copilot) — HIGH (Shogun does 4)
2. Skill/agent marketplace — HIGH (Orchestrator Kit has 39)
3. Context preservation for indefinite work — MEDIUM
4. Slash commands for common operations — LOW
5. Skill auto-discovery — LOW

### Recommended next features (based on competitor analysis)
1. **Multi-engine support** — let Aegis orchestrate Codex/Gemini sessions, not just CC
2. **Agent marketplace** — community-contributed skills/agents for Aegis
3. **Context-aware routing** — auto-pick the best engine for a task type
