- Research preview, requires claude.ai login (NOT API key)
- Only works while session is open
- Plugins: telegram, discord, imessage (from claude-plugins-official)

**Impact on Aegis:**
- Aegis Telegram integration is MORE capable (multi-session, API key auth, background mode)

- Aegis differentiator: multi-session orchestration, dashboard, SSE, WebSocket terminal
