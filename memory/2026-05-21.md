## #3888 — ag init project-local stateDir (04:53-05:14 UTC)

**Issue:** `ag init --yes` wrote state (keys.json, auth-token) to ~/.aegis/ instead of project-local .aegis/

**Root cause:** `loadConfig()` returned global config's stateDir (~/.aegis). init.ts used that for AuthManager and mkdir.

**Fix:** When creating a new config (no existing file), set stateDir to `dirname(configPath)`. Persist in config. Use for AuthManager + auth-token. Respect AEGIS_STATE_DIR env override.

**Changes:** src/commands/init.ts, src/__tests__/cli-init.test.ts (2 new tests)
