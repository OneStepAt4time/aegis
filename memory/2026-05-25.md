## 09:30–10:00 CEST — #4158 CLI audit triage

### Boss's 3 CLI bugs — assessment

1. **`ag init --defaults` still prompts** — **No such flag exists.** The flag is `--yes` / `-y`. Not a bug, possibly a docs misunderstanding.

2. **`ag init` doesn't create API token** — **By design on localhost.** Zero-config mode skips auth. Token creation is offered in interactive mode when non-localhost. The `--yes` flag on localhost also skips token creation (correct for zero-config).

3. **`ag run` from /tmp blocked** — **Intentional security (#2945).** System temp dirs are explicitly excluded from default safe dirs. Error message tells users to add to `allowedWorkDirs`. Not a bug.

### Additional finding from #4158
- **`ag status` shows "0 total"** — This is a symptom of #4149 (metrics persistence loss on restart). Fixed by PR #4163 (awaiting merge). Not a separate bug.

### Recommended env var additions from Scribe
- `AEGIS_ALLOWED_WORKDIRS`, `AEGIS_RATE_LIMIT`, `AEGIS_STALL_THRESHOLD_MS`, `AEGIS_DEFAULT_PERMISSION_MODE` — worth adding, low risk, good for CI/CD.
