## Dogfooding Bug — Stall Detection

**Sessione:** `61a4475b-eb19-467b-9ef7-294a0fca7ad4`
**Data:** 2026-04-07
**Tipo:** Bug Aegis

### Problema
CC entrato in "Cogitated for 2m 54s" status per 3+ minuti. Il `stallThresholdMs` non ha triggato. Nudge via `POST /send` non ha risposto.

### Root Cause
Il campo `statusText` mostra "Cogitated for Xm Ys" ma Aegis non considera questo come una condizione di stall. Il check `stallThresholdMs` si basa solo su `lastActivity` timestamp, non sul statusText.

### Fix Suggerito
In `monitor.ts` o `session.ts`, aggiungere check per:
```typescript
if (statusText.includes("Cogitated") && parseDuration(statusText) > stallThresholdMs) {
  // Trigger stall notification
}
```

### Severity
Medium — CC non è bloccato permanentemente, ma il nudge non funziona durante thinking mode.
